# Python Design — Nirmana Generator

Generate pattern nirmana secara procedural menggunakan Python, ditujukan untuk kebutuhan mikrostok.

## Setting Standar

| Parameter | Nilai |
|-----------|-------|
| Rasio | 1:1 (Persegi) |
| Resolusi | 4000 x 4000 px |
| DPI | 300 |
| Format | PNG + SVG |

## Tech Stack

- Python 3.x
- Matplotlib
- NumPy

## Instalasi

```bash
pip install matplotlib numpy
```

## Mikrostok Naming Guide

### Format Nama File

```
[deskripsi_utama]_[elemen_desain]_[gaya]_[variasi]
```

### Keywords yang Sering Dipakai

| Kategori | Keywords |
|----------|----------|
| Elemen | lines, dots, shapes, circles, squares, triangles |
| Gaya | abstract, geometric, minimalist, seamless, pattern |
| Warna | black, white, monochrome, grayscale, contrast |
| Tekstur | texture, sketch, crosshatch, hatching |
| Efek | optical, illusion, moire, gradient, density |
| Komposisi | radial, parallel, converging, crossing, spiral |
| Kegunaan | background, wallpaper, textile, print, fabric |

### Tips Upload Mikrostok

1. **Judul**: Gunakan deskripsi jelas, hindari judul generik
2. **Tags**: Minimal 10-15 tags relevan
3. **Kategori**: Pilih yang tepat (Pattern, Texture, Background)
4. **Deskripsi**: Jelaskan pola, warna, nuansa, dan kegunaan
5. **Disclosure**: Tambahkan label "AI-generated" atau "Code-generated"
